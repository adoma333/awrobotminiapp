# أيقونات متحركة (WebM)

ضع هنا ملفات WebM (VP9 بخلفية شفافة، مربعة، ≤ 300KB) بنفس اسم الأيقونة لتحلّ محلها تلقائيًا:

- المستويات: `bronze.webm` `silver.webm` `gold.webm` `platinum.webm` `diamond.webm` `master.webm`
- الجوائز: `discount.webm` `free_days.webm` `slippage_insurance.webm` `free_month.webm` `funded_challenge.webm`

بلا ملف (أو على جهاز لا يدعم WebM مثل iOS القديم) تُعرض صورة webp الحالية كما هي.
